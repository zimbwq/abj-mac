# abj for Mac — Apple Silicon

[**Скачать abj для Mac (ZIP)**](https://github.com/zimbwq/abj-mac/releases/latest/download/abj-mac-arm64.zip)

Отдельная Mac-версия [abj](https://github.com/zimbwq/abj): macOS **15 и новее**, процессоры Apple M1/M2/M3/M4 и новее (arm64). Python устанавливать не нужно. Windows-версия остаётся в исходном репозитории.

## Запуск

1. Распакуйте ZIP и перенесите `abj.app` в удобную постоянную папку, например «Программы». Установка через мастер не нужна.
2. Откройте приложение. В строке меню появится **abj**.
3. При первом запуске выберите **OpenAI** или **Gemini**, введите свой API-ключ и нажмите «Применить». Ключ, провайдер и модель сохранятся в системной **Связке ключей macOS**; при следующих запусках ввод не потребуется. Поле модели можно оставить пустым: используются `gpt-5-mini` или `gemini-4-hydrogen`. Можно указать другую доступную вашему ключу модель с поддержкой изображений и JSON Schema.
4. В меню **abj → Разрешения macOS…** запросите разрешения. В **Системные настройки → Конфиденциальность и безопасность** включите для abj **Запись экрана** и **Универсальный доступ**. Полностью закройте и снова откройте приложение после изменения разрешений.
5. Три быстрых левых клика в одном месте (за 0,65 секунды) отправляют снимок **основного экрана** выбранному провайдеру. Можно также выбрать **Снять экран** в меню.
6. Ответ появляется серым текстом справа внизу. **Esc** или **Скрыть ответ** убирают его; по умолчанию он исчезает через 25 секунд (всё это можно изменить в «Настройка текста…»). Тройной клик можно отключить в меню. **Выход** завершает приложение.

## Настройка текста и живой предпросмотр

Откройте **abj → Настройка текста…**. На рабочем столе сразу появится тестовый ответ. Окно настроек можно перемещать, чтобы видеть текст под ним. Предпросмотр не снимает экран и не обращается к API; новые запросы на время настройки приостановлены.

- **Время показа:** 1–300 секунд; 0 — до закрытия. Кнопка **Проверить время** запускает таймер на тестовом ответе. При обычном редактировании предпросмотр остаётся видимым.
- **Положение:** семь вариантов (углы, верх/низ по центру, центр), плюс отступ от края 0–200.
- **Размер шрифта:** 10–72 pt. **Ширина блока:** 180–1200, ограничивается доступной областью экрана.
- **Цвет:** системная палитра macOS. **Непрозрачность:** 15–100%.
- **Клавиша скрытия:** по умолчанию Esc. Нажмите кнопку с названием клавиши, затем нужную клавишу или сочетание (например, ⌘⇧X). Повторное нажатие проверит скрытие предпросмотра. При смене раскладки используется та же физическая клавиша. Системные сочетания могут перехватываться macOS; для функциональных клавиш может требоваться Fn. В других приложениях сочетание не блокируется и всё ещё требует «Универсального доступа».
- **Применить** сохраняет настройки между запусками; **Отмена** или закрытие окна отбрасывают изменения. **Сбросить** возвращает стандартные значения в предпросмотре; сохранение — только через «Применить».

Настройки оформления хранятся в `~/Library/Application Support/abj/overlay.json`, без API-ключей. Длинный ответ может обрезаться по высоте экрана: уменьшите шрифт или увеличьте ширину блока.

## API-ключи

- OpenAI: ключ из [OpenAI API Platform](https://platform.openai.com/api-keys). Подписка ChatGPT не заменяет API-ключ и отдельную квоту API.
- Gemini: ключ из [Google AI Studio](https://aistudio.google.com/apikey). Используется официальный совместимый API Google.
- Поддерживаются действующие ключи этих двух сервисов с доступом к выбранной модели. Ключи других поставщиков, токены входа ChatGPT и Vertex AI credentials не поддерживаются.
- Ключ, провайдер и модель сохраняются только в **Связке ключей macOS**, в записи `io.github.zimbwq.abjmac` / `saved-session`. Файл `api-key.txt` и переменные окружения не читаются. При смене провайдера введите соответствующий ключ заново; сохраняется последний выбранный провайдер. Для текущего провайдера пустые поля сохраняют текущий ключ и модель.
- Меню **Удалить сохранённый ключ** удаляет запись и отключает запросы до ввода нового ключа. При удалении самого приложения запись в Связке ключей остаётся: удалите её через меню abj заранее или через «Связку ключей».
- macOS может запросить доступ к Связке ключей, особенно после обновления приложения без сертификата Apple Developer. Если доступ отклонён, abj сообщит об ошибке и предложит ввести ключ. Обхода системных запросов нет.
- Ключ и снимок отправляются только выбранному провайдеру. Автоматического переключения на другой сервис нет. Перенаправления запросов запрещены.
- Приложение не ведёт журнал снимков или ответов. Pillow может использовать временный файл для системного захвата, который удаляется после чтения. В кадр попадает всё содержимое основного экрана — учитывайте это перед запуском запроса.

## Подпись и проверка

Сборка подписана **ad-hoc**, без сертификата Apple Developer и без notarization. macOS может заблокировать первый запуск. Ознакомьтесь с [официальной инструкцией Apple](https://support.apple.com/102445) и разрешайте запуск только если доверяете исходникам и происхождению файла. Не отключайте Gatekeeper или другие системные защиты.

GitHub Actions собирает приложение на **macos-15 arm64**, проверяет архитектуру, подпись, unit-тесты и запуск настоящего Cocoa-интерфейса из исходников и готового `.app`. В релиз включены `SHA256SUMS.txt` и отчёты проверок.

**Ограничение проверки:** CI не подтверждает работу разрешений пользователя, реального захвата экрана, глобального тройного клика/Esc и платных запросов API. Эти сценарии необходимо проверить на пользовательском Mac. Точность ответов модели не гарантируется. Длинные ответы могут не помещаться в оверлей. Захватывается основной монитор; внешние мониторы отдельно не захватываются.

## Разработка

На Mac Apple Silicon с Python 3.12:

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt 'pyinstaller>=6.16,<7'
python -m unittest discover -s tests -v
python mac_app.py
python -m PyInstaller --clean --noconfirm abj.spec
```

`python mac_app.py --self-test report.json` проверяет интерфейс с синтетическим ответом, а также сохранение, чтение и удаление отдельной тестовой записи в Связке ключей. Пользовательские ключи не читаются, снимки и запросы в сеть не выполняются. Для запуска из исходников разрешения могут требоваться Terminal/Python; для готовой сборки — самому abj.

Протокол ответа и принцип прямого анализа снимка перенесены из `zimbwq/abj`; интерфейс Mac реализован на AppKit/PyObjC, без Win32, Tkinter и pystray.

## Если Esc не скрывает ответ

Глобальный Esc требует «Универсального доступа», хотя тройной клик мыши может работать без него. Проверьте **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ → abj**. В версии 1.1.1 меню показывает отсутствие разрешения и обработчик обновляется после его выдачи. После замены приложения может потребоваться удалить старую запись разрешения, добавить текущий `abj.app` и перезапустить приложение. Пока разрешение не выдано, используйте **abj → Скрыть ответ**. Esc также отменяет показ ещё ожидаемого ответа; уже отправленный API-запрос этим не отменяется.
